# Retail-Dashboard
This dashboard was created as one of my first Power Bi projects

Description of project:
The project was done to visualize the total profits and sales for a retail company. 
- It included 3 static Kpi cards.
- Simulator for discount effect on total profits/sales.
- Total sales per region.
- Detailed total sales matrix to show products and their separate revenues. 

Data Source:
The data found in the dashboard was obtained as sample data through Claude Ai.
